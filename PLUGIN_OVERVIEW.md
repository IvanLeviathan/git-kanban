Работайте с GitHub Issues выбранного BB-проекта в Kanban прямо в BB.

## Доска GitHub Issues

Выберите BB-проект с GitHub remote. Плагин загружает открытые и закрытые Issues и labels напрямую из репозитория. Выбранный проект запоминается при следующем открытии. Каждая доска использует stage-labels вида `stage:10:Backlog`; число задаёт порядок, а цвет label окрашивает колонку и карточки. Обычные labels остаются метками Issue. Issues без стадии и с конфликтующими стадиями отображаются отдельно. Доска обновляется каждые 30 секунд и при возвращении в окно.

## Изменения сразу в GitHub

Создавайте Issues, меняйте их стадии и оставляйте комментарии в GitHub из плагина. Stage-labels и обсуждение остаются в репозитории; копии Issue и настройки доски локально не сохраняются. Для API используется авторизация GitHub CLI `gh`.

GitHub Actions закрывает Issues в стадиях `Done` и `Canceled`, снимает label `closed` при повторном открытии и открывает Issue, если его перенести в любую другую стадию. Закрытые Issues остаются на доске и доступны для переноса.
